# PRD: 桌面通知

审批门上线后,用户切到别的应用时 agent 卡在待审批/完成/失败上无感知。加系统通知补全「多会话并行」体验。

## 需求

1. 触发:待审批(approval-request)、轮完成(turn-completed)、会话失败(status failed)。
2. **仅当主窗口未聚焦时**通知(前台工作不打扰)。
3. 点击通知:聚焦主窗口 + 切到对应会话。
4. 文案走 shared i18n(读 settings 的 language)。
5. 不加设置开关(v1 默认开)。

## 验收

- 后台时审批请求/轮完成弹系统通知,点击回到对应会话;前台时不弹。全绿。
