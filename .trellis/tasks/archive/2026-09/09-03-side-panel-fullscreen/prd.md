# 右侧侧边栏全屏

## Goal

给右侧侧边栏（Side Panel）加全屏，交互对齐 Cursor / DimAgent：一键把面板铺满中间工作区，方便看终端、Browser、Changes、Files。

## Requirements

- 右侧面板打开时，可进入 / 退出全屏。
- 全屏时面板铺满**中间工作区**（原 Chat 区域），**左侧会话栏保持可见**（折叠态也保留）。
- 标题栏、窗口红绿灯 / 窗口按钮保持可见；不是操作系统窗口全屏。
- 入口：dock 分组标题栏右侧（`+` 新建标签旁）放 Maximize / Minimize 按钮。
- 快捷键：可配置，默认 `mod+shift+j`（与现有 `mod+j` 开合面板成对）。远程节点态不响应。
- `Esc` 在全屏时退出全屏；不关闭面板。
- 关闭右侧面板时同时退出全屏。再次打开回到上次保存的普通宽度，不自动全屏。
- 全屏状态**不持久化**（刷新 / 重启后是普通宽度）。
- 全屏时隐藏 Chat 与右侧拖拽手柄，但 Chat 保持挂载（会话 / composer 状态不丢）。
- 全屏宽度不受普通上限 800px 限制；退出后恢复进入全屏前的宽度。
- Browser 视口跟随面板尺寸（沿用现有 rAF `setViewport`）。
- 新文案走 `t()`，并补中文。

## Out of scope

- 不盖住左侧会话栏。
- 不改 dock 分屏逻辑、不新增面板类型。
- 不做独立浮动窗。
- 不改远程节点视图（本机 Side Panel 本就不渲染）。

## Acceptance Criteria

- [ ] 打开右侧面板后，标题栏操作区或 dock 标题栏能一键全屏；全屏后 Chat 被盖住，左侧栏仍在。
- [ ] 再点一次或按 `Esc` / 默认快捷键可退出全屏，宽度回到进入前。
- [ ] 全屏时关面板，再开是普通宽度，不是全屏。
- [ ] 设置页能看到并改绑全屏快捷键；远程节点态快捷键无效。
- [ ] Browser / Terminal 等在全屏后能铺开，退出后回到侧栏宽度。

## Notes

- 轻量任务，PRD-only。
- 参考：Cursor / DimAgent 的侧栏 Maximize，而不是 Electron `setFullScreen`。
